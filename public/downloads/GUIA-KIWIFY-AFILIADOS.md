## PARTE 1: CADASTRO NA KIWIFY

### 1.1 Criar conta Kiwify

1. Acesse **https://kiwify.com.br**
2. Clique em **"Criar conta"** (canto superior direito)
3. Preencha:
   - Nome completo
   - Email (use o mesmo do MeuCorre: clodoaldo608@gmail.com)
   - Senha
   - CPF/CNPJ (use o CNPJ do MEI)
4. Confirme o email (clique no link que a Kiwify envia)
5. Complete o perfil:
   - Telefone
   - Endereço
   - Dados bancários (conta para receber pagamentos)

### 1.2 Verificar conta

Para receber pagamentos, a Kiwify exige verificação:

1. Envie foto do RG ou CNH (frente e verso)
2. Envie comprovante de residência
3. Aguarde 24-48h para aprovação
4. Após aprovação, pode criar produtos e receber pagamentos

## PARTE 3: CONFIGURAR PROGRAMA DE AFILIADOS

### 3.1 Habilitar afiliados para cada produto

Para cada produto criado, habilite o programa de afiliados:

1. No painel Kiwify, vá em **"Produtos"**
2. Clique no produto (ex: "10 Erros que Entregadores Cometem")
3. Vá na aba **"Afiliados"**
4. Ative o toggle **"Permitir afiliados"**

### 3.2 Configurar comissão

Escolha o modelo de comissão. Recomendação MeuCorre:

| Produto | Preço | Comissão | Afiliado recebe | Você recebe |
|---------|-------|----------|-----------------|-------------|
| E-book 10 Erros | R$ 27 | 50% | R$ 13,50 | R$ 13,50 |
| E-book Gestão Financeira | R$ 97 | 30% | R$ 29,10 | R$ 67,90 |
| Curso Premium | R$ 247 | 30% | R$ 74,10 | R$ 172,90 |

**Por que essas comissões?**

- **50% no e-book de R$ 27**: comissão alta atrai muitos afiliados. Eles divulgaram um produto barato (fácil de vender) e ganham R$ 13,50 por venda. Para 100 vendas via afiliados, você ganha R$ 1.350 sem esforço de marketing.

- **30% no e-book de R$ 97**: comissão média. Produto de ticket maior precisa de comissão menor para preservar margem. Afiliado ainda ganha bem (R$ 29 por venda).

- **30% no curso de R$ 247**: comissão média em high-ticket. Afiliado ganha R$ 74 por venda — motivador forte para divulgar.

### 3.3 Configurar regras do programa

Na aba "Afiliados" de cada produto:

**Cookie de referência:** 30 dias (padrão)
- Se alguém clicar no link de afiliado e comprar em até 30 dias, o afiliado ganha a comissão

**Pagamento de comissão:** Após 7 dias da venda
- Evita fraudes com estornos
- Kiwify paga afiliado automaticamente

**Limite de afiliados:** Sem limite
- Quanto mais afiliados, mais vendas

**Aprovação automática:** Sim
- Qualquer um pode se afiliar sem necessidade de aprovação manual

### 3.4 Criar página de afiliados

Crie uma página pública explicando o programa:

1. No painel Kiwify, vá em **"Afiliados"** → **"Página de afiliados"**
2. Configure:
   - Título: `Programa de Afiliados MeuCorre`
   - Descrição: `Ganhe dinheiro divulgando produtos que ajudam entregadores`
   - Comissões: liste os 3 produtos e comissões
   - Bônus para afiliados que vendem muito: ex: 10 vendas no mês = +5% de comissão

3. Salve e copie a URL (algo como `https://kiwify.app/afiliados/MeuCorre`)

### 3.5 Divulgar o programa de afiliados

Para atrair afiliados:

1. **Poste no Instagram/TikTok:** "Vire afiliado MeuCorre e ganhe R$ 13-74 por venda divulgando produtos para entregadores. Cadastre-se: [link]"

2. **Compartilhe no grupo WhatsApp do MeuCorre:** Muitos entregadores têm audiência e podem se afiliar.

3. **Procure influenciadores do nicho:** Contate perfis de motociclistas, entregadores, empreendedores digitais com 5k+ seguidores. Ofereça afiliação.

4. **Crie material de divulgação:** Banners, copy prontos, vídeos curtos. Facilite para afiliados divulgarem.

5. **Pague comissões em dia:** Kiwify faz automático, mas monitor para garantir que afiliados recebam. Afiliado bem pago divulga mais.

## PARTE 4: INTEGRAR COM O MeuCorre

### 4.1 Atualizar URLs dos produtos no banco

Após criar os produtos na Kiwify, você terá URLs de checkout (algo como `https://pay.kiwify.com.br/abc123`). Atualize o banco de dados:

```sql
-- Atualizar URLs dos produtos com links reais do Kiwify
-- (substitua PLACEHOLDER pelos slugs reais)

UPDATE "AffiliateProduct" SET
  "url" = 'https://pay.kiwify.com.br/SEU_SLUG_10_ERROS',
  "notes" = 'E-book criado! 20+ páginas. Produto ativo na Kiwify com afiliados habilitados (50% comissão).',
  "updatedAt" = NOW()
WHERE "id" = 'ebook_financas_entregador';

UPDATE "AffiliateProduct" SET
  "url" = 'https://pay.kiwify.com.br/SEU_SLUG_GESTAO',
  "notes" = 'E-book criado! 60+ páginas. Produto ativo na Kiwify com afiliados habilitados (30% comissão).',
  "updatedAt" = NOW()
WHERE "id" = 'course_gestao_financas';

UPDATE "AffiliateProduct" SET
  "url" = 'https://pay.kiwify.com.br/SEU_SLUG_PREMIUM',
  "notes" = 'Curso premium com 15 módulos × 10 capítulos = 150 capítulos. Estrutura completa + Módulo 1 já escrito. Afiliados habilitados (30% comissão).',
  "updatedAt" = NOW()
WHERE "id" = 'course_premium_avancado';
```

### 4.2 Adicionar página de produtos no site MeuCorre

Crie uma página `/produtos` no site que liste os 3 produtos com botões "Comprar" que redirecionam para o checkout Kiwify.

Também adicione links no:
- Rodapé do site
- Menu do app
- Bio do Instagram/TikTok (use Linktree ou similar)
- Posts de lançamento

### 4.3 Configurar webhook de vendas (opcional)

Para registrar vendas automaticamente no admin MeuCorre:

1. No painel Kiwify → **"Integrações"** → **"Webhooks"**
2. Adicione webhook URL: `https://meucorre.vercel.app/api/webhooks/kiwify`
3. Eventos: `order_approved`, `order_refunded`
4. A Kiwify vai enviar POST para sua API com dados da venda
5. Sua API cria uma entrada em `RevenueEntry` com source "products"

## PARTE 5: ESTRATÉGIA DE LANÇAMENTO

### 5.1 Pré-lançamento (7 dias antes)

- Teaser no Instagram: "Em 7 dias, vou lançar o e-book que vai mudar sua vida de entregador"
- Liste de espera: colete emails de interessados (formulário gratuito no Mailchimp ou Tally)
- Conteúdo educativo nos stories: mostre trechos do e-book

### 5.2 Lançamento (Dia 1-7)

- **Dia 1:** Anúncio oficial com link de compra
- **Dia 2:** Post com depoimento de quem já leu (peça amigos para lerem antes)
- **Dia 3:** Story ao vivo respondendo perguntas sobre o e-book
- **Dia 4:** Reels com "3 dicas do e-book"
- **Dia 5:** Carrossel com "10 erros que entregadores cometem"
- **Dia 6:** Post com bônus: "Compre hoje e ganhe X"
- **Dia 7:** Última chance de preço promocional

### 5.3 Pós-lançamento (após 7 dias)

- Aumente o preço (se fez promoção de lançamento)
- Colete depoimentos de compradores
- Use como prova social em novos posts
- Comece a planejar o próximo produto

### 5.4 Programa de afiliados ativo

- Anuncie o programa de afiliados em todos os canais
- Recrute 10-50 afiliados nos primeiros 30 dias
- Forneça material de divulgação (banners, copy, vídeos)
- Acompanhe vendas via afiliados no painel Kiwify
